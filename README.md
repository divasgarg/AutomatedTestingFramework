# Automated Testing Framework

A small Maven starter for Java testing. The [sample JUnit test](src/test/java/com/divasgarg/AppTest.java) registers a test suite and runs a placeholder assertion, giving you a starting point for adding checks of your own.

## Run the tests

With Java and Maven installed, run `mvn test` from the repository root.
